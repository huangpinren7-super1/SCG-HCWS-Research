# SCG-HCWS experiments

All theory-facing computations must bind to explicit frozen definitions, source inputs, tool versions, precision, expected controls, and a reproducible receipt.

Suggested families:

- exact-algebra — rings, ideals, centers, decompositions, sections and factorization maps.
- high-precision — arbitrary-precision values, interval/ball arithmetic and PSLQ proposals.
- spectral — finite-dimensional operators, fixed points, spectra and effective dynamics.
- counterexamples — finite-size exhaustive searches and adversarial constructions.
- scg-hcws — computations attached to the frozen SCG-FM / HCWS interface.

A battery PASS is evidence that a package's acceptance contract passed; it is not by itself a proof of a research theorem.
