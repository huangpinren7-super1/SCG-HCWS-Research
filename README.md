# SCG-HCWS-Research

Cloud research laboratory for SCG/HCWS and reproducible quantitative science.

BootLoops is an external, pinned computational dependency.

Current laboratory layers:
- BootLoops Acceptance: 49-package canonical battery on Ubuntu 24.04.
- Local resident layer: reusable Python scientific stack plus explicit engine lanes.
- Standardized interface: bootloops_lab catalog/guide/acceptance/receipt API.
- Gateway: allowlisted local interface with optional MCP stdio transport.

The present work is infrastructure-first. Theory proofs and SCG/HCWS claim attacks are kept outside the foundation layer.
